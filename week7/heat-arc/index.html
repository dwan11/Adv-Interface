Heat Arc

Tone: charged, kinetic, warm-blooded. Soft lilac triangles fan out of a glowing plum core, and every touch heats a tile up, layer by layer, like a heat map. Function: pick one tool from a small set without leaving the canvas.

Every tool rests cool until you touch it. Then it warms, glows, runs hot, and the heat travels home to the core that holds it.

States

Each state adds heat. Enabled is cool lilac. Hover warms the tile with a pale orchid rim and lifts it outward. Press fills it with heat. Selected grows the tile into a living heat map: dark core, bright orchid ring, plum body, pale rim and a violet halo that breathes.

Selecting: melt and return

Tiles leave the core as circles and flow into rounded triangles as they fan out. Choosing one reverses it: the triangle melts back into a round heat ball, the ball sinks into the core, the other tiles round off and fold away, and the core flares with the new tool.

System

Structure

  • Core: 60 px heat-map circle, shows the current tool
  • Tiles: separate rounded triangles, tip toward the core, outer edge following the arc
  • Depth 80 (icon, text) · 92 (icon + text); 10 px gaps
  • Icons and labels stay upright

Alignment

  • Center: arc up to 160° over the core
  • Left: core in the left corner, 100° sweep clockwise
  • Right: mirrored
  • Radius grows so each outer edge keeps ~95 px

Colour

  • Base: lavender page, lilac tiles, plum ink
  • Heat: dark core → orchid ring → plum body → pale rim → violet halo, all one purple spectrum

Motion

  • Open: tiles fan out of the core on a spring (k 210, c 17), 36 ms apart
  • Open: each tile leaves the core as a circle and flows into a rounded triangle (620 ms)
  • Select: heat floods in and the triangle melts into a circle (320 ms), the ball sinks into the core (380 ms, ease-in), the others round off and fold, and the core flares with the new tool
  • Selected tile and core breathe on a 2.6 s cycle
