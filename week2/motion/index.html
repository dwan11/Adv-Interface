Motion Study

Week 2

Fewer graphics, more motion. Each set is an icon sitting in an app’s banner: the same icon, the same badge dot, the same tooltip plane. Only colour and movement change, and the movement carries the tone. Each set is shown inside an app on desktop (hover with a cursor) and on mobile (long-press).

  • Banner · the app bar
  • Icon · one line glyph
  • Dot · the badge (point)
  • Line · stem or string
  • Plane · the tooltip
